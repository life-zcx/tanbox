## Повторение проверок

Нужны Node 22, Python 3 и установленные зависимости проекта. На проверяемом коммите сначала собрать backend и генератор (`npm run build` в каждом каталоге); для browser probes — также три фронтенда. Не запускать настоящий backend и не задавать production DATABASE_URL.

Из корня репозитория:

```powershell
python audit/2026-11-05/run-probes.py
python audit/2026-11-05/run-probes.py --browser original
python audit/2026-11-05/run-probes.py --browser canonical
```

Runner создаёт новый временный каталог, задаёт синтетические параметры и переносит туда fixtures. Все создаваемые ими uploads/backups/logs остаются в этом каталоге; путь выводится при запуске. Исходники приложения runner не меняет. Фикстуры работают с текущим `backend/dist`, поэтому после изменения исходников нужна новая сборка.

Для браузера нужен установленный Chromium/Chrome/Edge, при необходимости указать `CHROME_PATH`. Browser scripts — копии штатного smoke с корнем из `AUDIT_REPO` и блокировкой внешних адресов приложения. В canonical-копии дополнительно заменено одно ожидание `/en/blog/` на `/en/articles/`. Это диагностическое изменение тестовой копии, не исправление CI.

**Ожидаемый результат на аудированном коммите:** основной runner успешен (21 сценарий воспроизведения плюс матрица/SQL/backup); browser original завершается ошибкой A18; browser canonical успешен. После исправлений часть probes должна перестать проходить: они утверждают наличие дефекта. Не включать их как регрессионные требования неправильного поведения.

## Состав evidence

- `probes.cjs`, `probes.log`: реальные обработчики, mock Prisma и внешних сервисов, запрещённые немокированные HTTP-вызовы; 21 сценарий.
- `route-matrix.cjs`, `route-matrix.json`: реальные routers/middleware, инертные контроллеры, локальный HTTP; 145 операций.
- `db-invariants.cjs`: миграции в PGlite в памяти, без подключения к PostgreSQL.
- `backup-probe.cjs`: фиктивный pg_dump; настоящий shell dump не запускается.
- `browser-smoke*.cjs`: изолированный профиль Chromium и локальные API fixtures.
- `build-*.log`, `audit-*.json`, `tests-backend.log`: результаты штатных команд; `replay-*.log` — контрольный запуск упакованных probes.
- `secret-scan.json`: только типы, пути и хеши Git-объектов, значения заменены на `[REDACTED]`.
- `compose-fixture.env`: только вымышленные реквизиты для разбора Compose.
- `integrity.json`: сравнение SHA-256 отслеживаемых файлов до/после аудита.
- `findings.json`: перечень находок и уровней для машинной проверки количества.
